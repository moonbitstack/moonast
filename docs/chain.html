The declaration is annotated

The annotation is the whole interface. It sits above a declaration you already wrote, names the generator that should run, and changes nothing else about the code it annotates.

Why the order matters

Each stage only knows what the one before it gave

A stage is a package, and a package is usable alone. That is what keeps a generator small: gen never opens a file, quote never reads a declaration, attr never sees a template. The only package that touches the disk is cli.

It also decides where a mistake is caught. A template that is not MoonBit fails in quote, before anything is written. An annotation argument of the wrong kind fails in attr, with the annotation's line and column. An input that is not MoonBit fails in gen, naming the file.

A generator that refuses leaves the old file where it was. Half a file is never written.
