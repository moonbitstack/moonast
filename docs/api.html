quotemoonbitstack/moonast/quote

Templates: real MoonBit with $holes. A template is parsed with its holes standing as placeholders, each fill is put where its placeholder stands, and the result is printed by the official formatter.

pub struct Template { #

A piece of MoonBit with holes, waiting to be filled and rendered.

A hole is $name; write it in the case the position wants, $T where a type or constructor goes and $name where a value or a name goes. $name* takes a list and expands among statements, array elements or positional arguments. $$ is a literal dollar sign.

pub fn Template::render(Self) -> Code raise Refused #

Parse the template with its holes standing as placeholders, put each fill where its placeholder stands, and give back the result. Refused when a hole is left empty, a fill names no hole, a fill does not fit where it stands, or the template is not MoonBit.

let text = @quote.items("fn $name() -> Unit { () }").render().to_string() catch {
e => e.to_string()
}
inspect(text, content="hole $name was given nothing")
pub fn Template::set(Self, String, Code) -> Self #

Fill $hole with code.

let t = @quote.items("fn $name() -> Unit { () }").set(
"name",
@quote.ident("answer"),
)
inspect(
t.render().to_string(),
content="///|\nfn answer() -> Unit {\n  ()\n}\n",
)
pub fn Template::splice(Self, String, Array[Code]) -> Self #

Fill $hole* with codes, in order.

let code = @quote.expr("[$items*]")
.splice("items", [@quote.int(1), @quote.int(2), @quote.int(3)])
.render()
inspect(code.to_string(), content="[1, 2, 3]")

Errors

pub(all) suberror Refused { #

Why a template or a code was not accepted. Each variant is named after the thing that was wrong.

  • Template(msg~ : String, line~ : Int32, column~ : Int32) — The template is not MoonBit once its holes are in place.
  • Unfilled(hole~ : String) — A hole in the template was given nothing.
  • Unused(hole~ : String) — Something was given for a hole the template does not have.
  • Misfit(hole~ : String, expected~ : String) — A hole was given a code of the wrong kind for where it stands.
  • Name(name~ : String) — ident was given something that is not an identifier.
  • Kind(expected~ : String) — join was given a code that is not declarations.

Errors

pub(all) suberror Refused { #

Why an annotation's arguments were not accepted, with where the annotation stands in its file.

  • Malformed(raw~ : String, line~ : Int32, column~ : Int32) — The payload is outside the annotation grammar: arrays, numbers, a qualified or generic type cannot be written, and a keyword cannot be a label.
  • Missing(key~ : String, line~ : Int32, column~ : Int32) — A required parameter was not given.
  • Unknown(key~ : String, line~ : Int32, column~ : Int32) — A parameter the spec does not have.
  • Mistyped(key~ : String, expected~ : String, line~ : Int32, column~ : Int32) — A parameter of the wrong kind.
  • Repeated(key~ : String, line~ : Int32, column~ : Int32) — A parameter given twice that may only be given once.

genmoonbitstack/moonast/gen

Declarations read from source into plain views, the Generator trait, and render, which gives the file a generator writes. No file access here.

Values

pub fn read(String, String) -> Array[Decl] raise Refused #

The declarations of one file, in source order. Refused when the file is not MoonBit, with the first problem's position.

let source = "pub struct Point {\n  x : Int\n  y : Int\n}"
guard @gen.read("models.mbt", source) is [Struct(name~, fields~, ..)] else {
abort("a struct")
}
inspect(name, content="Point")
inspect(fields.map(f => f.name).join(", "), content="x, y")
pub fn render(&Generator, Array[(String, String)]) -> String raise #

The file a generator writes for inputs: a one-line header naming the generator and the inputs, then the code. The same inputs give the same bytes, so a check can compare them.
